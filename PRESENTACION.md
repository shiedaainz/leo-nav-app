# Presentacion de Leo

## 1. Introduccion

Buenos dias.

Hoy presentamos **Leo**, una aplicacion pensada para ayudar a estudiantes, visitantes y personal universitario a orientarse mejor dentro de las sedes de la Universidad de Pamplona.

Leo nace de una situacion muy comun: llegar a una sede, buscar un salon, una biblioteca o un punto especifico, y no saber exactamente por donde ir.

La idea de Leo es simple: que cualquier persona pueda abrir la app, elegir a donde quiere ir y recibir una guia clara para llegar.

## 2. Problema

En una universidad, especialmente cuando hay varias sedes o espacios distribuidos, muchas personas pueden perder tiempo buscando un lugar.

Esto puede pasarle a:

- Estudiantes nuevos.
- Visitantes.
- Aspirantes.
- Padres de familia.
- Personas que no conocen bien las sedes.
- Estudiantes que tienen clases en diferentes puntos.

El problema no es solo no saber donde queda un lugar. Tambien es no saber cual camino tomar, cuanto se puede tardar o como ubicarse rapidamente desde el celular.

## 3. Solucion

Leo propone una solucion practica: una aplicacion web de navegacion universitaria.

Con Leo, el usuario puede:

- Buscar una sede o punto de interes.
- Verlo en el mapa.
- Iniciar una ruta.
- Recibir instrucciones.
- Usar su ubicacion actual si desea.
- Guardar horarios opcionales.
- Usar una camara guiada como apoyo visual.

La aplicacion esta pensada para usarse desde el celular, sin necesidad de instalar obligatoriamente nada.

## 4. Que es Leo

Leo es el asistente de navegacion de la app.

No es solo un logo. Leo acompana al usuario durante el recorrido, muestra mensajes y ayuda a entender que esta pasando.

Por ejemplo, Leo puede indicar:

- Que destino esta seleccionado.
- Que se recomienda activar la ubicacion.
- Que la ruta ya esta lista.
- Que se esta navegando hacia un lugar.
- Que el usuario ya llego cerca del destino.

La idea es que la experiencia sea mas amigable, no tan fria como un mapa tradicional.

## 5. Que hace la aplicacion

Leo tiene varias funciones principales.

### Mapa interactivo

El usuario puede ver un mapa con las sedes y puntos importantes.

Desde ahi puede seleccionar lugares como:

- Biblioteca.
- Entrada principal.
- Plaza central.
- Sede Casona.
- IPT.
- Sede Virgen del Rosario.
- Sede Club del Comercio.

### Busqueda de destinos

El usuario puede escribir el nombre de un lugar y la app lo busca.

Tambien hay botones rapidos para seleccionar destinos comunes sin escribir.

### Ruta recomendada

Antes de iniciar, Leo muestra una ruta recomendada con distancia aproximada y tiempo estimado.

Esto ayuda al usuario a entender cuanto debe caminar y hacia donde se dirige.

### Navegacion

Cuando se inicia la ruta, el mapa dibuja el recorrido y el panel inferior muestra las instrucciones.

La app puede calcular desde la entrada principal o desde la ubicacion actual del usuario si este activa el GPS.

### Horarios

Leo tambien permite guardar horarios manualmente.

Por ejemplo, un estudiante puede guardar una materia, la sede donde tiene clase, el dia y la hora.

Luego puede tocar el horario y abrir directamente la ruta hacia esa sede.

### Camara guiada

La app incluye una camara guiada basica.

Cuando hay una ruta activa, el usuario puede abrir la camara y ver una flecha sobre la pantalla como apoyo visual.

Esto no reemplaza el mapa, pero ayuda a que la experiencia sea mas cercana a una guia en tiempo real.

### Instalacion como app

Leo tambien esta preparado como PWA.

Esto significa que, cuando se despliega en internet, puede agregarse a la pantalla de inicio del celular como si fuera una aplicacion.

Pero esto es opcional. Si el usuario no quiere instalarla, puede usarla directamente desde el navegador.

## 6. Como funciona explicado facil

La app funciona como una guia de caminos.

Primero, tenemos puntos importantes dentro del mapa. Esos puntos representan lugares por donde una persona puede caminar o pasar.

Despues, esos puntos se conectan entre si formando caminos.

Cuando el usuario elige un destino, Leo revisa cual es el camino mas conveniente entre el punto de inicio y el destino.

Luego dibuja ese camino en el mapa y muestra instrucciones para seguirlo.

En palabras simples:

1. El usuario elige a donde quiere ir.
2. Leo mira desde donde empieza.
3. Leo revisa los caminos disponibles.
4. Leo escoge la ruta mas corta o conveniente.
5. Leo muestra la ruta en el mapa.
6. El usuario sigue las indicaciones.

## 7. Beneficios

Leo puede aportar varios beneficios.

### Para estudiantes

- Les ayuda a llegar mas rapido a sus clases.
- Reduce confusion en sedes que no conocen.
- Les permite guardar horarios y acceder a rutas rapidamente.

### Para visitantes

- Facilita encontrar lugares importantes.
- Mejora la experiencia al llegar a la universidad.
- Reduce la dependencia de preguntar constantemente.

### Para la universidad

- Mejora la orientacion dentro de sus espacios.
- Da una imagen mas moderna y organizada.
- Puede servir como base para una plataforma mas grande de servicios universitarios.

## 8. Que hace diferente a Leo

Leo no es solamente un mapa.

Lo que lo hace diferente es que esta pensado especificamente para navegacion universitaria.

A diferencia de un mapa general, Leo se enfoca en sedes, accesos, rutas internas, horarios y acompanamiento visual.

Ademas, el asistente Leo hace que la experiencia sea mas cercana y facil de entender.

## 10. Alcance actual

Actualmente Leo es un MVP, es decir, una primera version funcional.

Esta version ya permite demostrar la idea principal:

- Orientar al usuario.
- Calcular rutas.
- Mostrar mapas.
- Guardar horarios.
- Acompanarlo con Leo.
- Usar camara guiada basica.
- Instalarse como app web.

## 11. Limitaciones actuales

Como es una primera version, hay cosas que aun pueden mejorar.

Por ejemplo:

- Los usuarios y horarios se guardan en el navegador, no en una base de datos en internet.
- La camara guiada es basica, no es realidad aumentada avanzada.
- La app no reconoce objetos ni edificios con la camara.
- La ubicacion dentro de edificios no esta incluida.
- Las rutas dependen de los puntos que ya fueron registrados en el mapa.

Estas limitaciones son normales en un MVP, porque primero se busca demostrar que la idea funciona.

## 12. Futuro del proyecto

Leo puede crecer mucho mas.

En futuras versiones se podria agregar:

- Base de datos real para usuarios y horarios.
- Panel administrativo para registrar nuevas sedes y rutas.
- Mas salones y edificios.
- Notificaciones de clases.
- Mejoras en camara guiada.
- Integracion con servicios universitarios.
- Recomendaciones mas inteligentes.
- Rutas accesibles para personas con movilidad reducida.
- Informacion de oficinas, servicios y eventos.

## 13. Cierre

Leo busca resolver un problema cotidiano dentro de la universidad: la orientacion.

La propuesta no es solo mostrar un mapa, sino acompanar al usuario desde que abre la app hasta que llega a su destino.

Con Leo, la universidad puede ofrecer una experiencia mas clara, moderna y amigable para estudiantes y visitantes.

En resumen:

**Leo es una guia universitaria inteligente, visual y facil de usar.**
